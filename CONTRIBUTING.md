
# Contributing to CodeYantra Technologies

Thank you for your interest in contributing to
CodeYantra Technologies.

We welcome meaningful contributions that improve
software quality, security, accessibility, and reliability.

## Ways to Contribute

- Report bugs.
- Suggest improvements.
- Improve documentation.
- Fix existing issues.
- Add or improve tests.
- Improve performance and accessibility.
- Contribute security improvements responsibly.

## Before You Start

- Read the repository README.
- Review the project's license.
- Follow our Code of Conduct.
- Check existing issues to avoid duplication.
- Discuss major changes before implementation.

## Contribution Workflow

1. Fork the public repository.
2. Create a dedicated branch.
3. Implement your changes.
4. Run relevant tests.
5. Write clear commit messages.
6. Submit a pull request.
7. Respond to review feedback.

## Engineering Standards

All contributions should:

- Be readable and maintainable.
- Follow existing project architecture.
- Include relevant tests where applicable.
- Avoid unnecessary dependencies.
- Respect security and privacy requirements.
- Avoid exposing credentials or sensitive information.

## AI-Assisted Contributions

AI-assisted contributions are welcome.

However, contributors remain responsible for:

- Understanding the submitted code.
- Verifying correctness and security.
- Testing the implementation.
- Respecting intellectual property and licenses.
- Reviewing generated code before submission.

Unverified or low-quality automated contributions
may be rejected.

## Security Vulnerabilities

Do not report security vulnerabilities through
public issues.

Please follow our SECURITY.md policy for
responsible disclosure.

## Licensing

Contributions must comply with the license
and contribution requirements of the respective
repository.

Public availability does not automatically grant
permission to redistribute proprietary software.

## Review Process

All contributions are subject to maintainer review.

Submitting a contribution does not guarantee acceptance.
