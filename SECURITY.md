
# Security Policy

## Our Commitment

CodeYantra Technologies takes software security and user
privacy seriously. We welcome responsible vulnerability
disclosure from security researchers and developers.

## Reporting a Vulnerability

If you discover a potential security vulnerability in any
CodeYantra Technologies project, please report it privately.

Email: support@codeyantra.in

Subject: Security Vulnerability Report

Please include:

- Affected product or repository
- Vulnerability description
- Steps to reproduce
- Potential security impact
- Supporting evidence, if available

Please do not include personal user data, passwords,
access tokens, or other sensitive information.

## Responsible Disclosure

We request researchers to:

- Avoid publicly disclosing unresolved vulnerabilities.
- Avoid accessing or modifying other users' data.
- Avoid disrupting production services.
- Allow reasonable time for investigation and remediation.

## Our Response

We aim to acknowledge reports within 7 business days.

Resolution timelines depend on the severity and complexity
of the reported vulnerability.

## Bug Bounty

CodeYantra Technologies does not currently operate a paid
bug bounty program.

## Recognition

With their permission, we may acknowledge researchers
who responsibly disclose verified security vulnerabilities.
